THE TWO STYLES

HOW THE TEMPLATE WORKS

  • CUSTOMISE (right edge) puts a ◇ chip on every part. Tap a chip: a picker opens with every LIVE option for that slot. Tap one and it swaps instantly.
  • Under the live options, ALSO IN THE ARSENAL lists every catalogue item of that type (372 effects + 108 library modules, searchable). Tapping one saves it as a build request.
  • ALL SLOTS: 27 slots in one list (colour, background, texture, heading finish, fonts, menu, buttons, cards, hover, cursor, forms, loader, footer, and the 12 effects).
  • IMAGE DROP: drop a picture. Palette, background and texture re-spin from its measured pixels.
  • SAVE PICKS saves to the page database (I read it back to build the real site). SHARE LINK copies a link that carries the picks, for clients.

# LUXURY BENCHMARK
Owner: "It should look like a $20,000 to $50,000 website... I don't want it to look cheap."

## Steps
1. Pick 3 reference sites (premium health, wellness, luxury skincare or product sites; Awwwards-level). Use apex-design-capture to screenshot and note spacing, type scale, motion and section rhythm. Save under design/references/pepticity-benchmark/ (links and notes only, no copied code or assets).
2. Screenshot our page at the same scroll positions.
3. Score ours 1 to 5 against each on: whitespace, type hierarchy, restraint of colour, motion quality, depth and material, hook placement without clutter.
4. Anything under 4 gets fixed before the owner sees it. Run award-jury-review on the result.
5. Report: one picture (ours beside the references) and the scores in point form.

Study, never copy: original layouts, original assets.
